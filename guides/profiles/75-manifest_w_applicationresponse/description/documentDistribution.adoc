[[document-distribution]]
= Document distribution

`cac:DocumentDistribution` identifies an additional interested party to whom the Manifest is distributed, beyond the immediate receiving party. This can be used, for example, when a copy of the Manifest also needs to reach a terminal operator or another authority.
